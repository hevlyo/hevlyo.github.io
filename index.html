03 Open source

Ferramentas para trabalhar com agentes de IA.

Duas ferramentas de código aberto para quem coloca agentes de IA para trabalhar no terminal. As demos abaixo rodam no seu navegador.

P/01Segurança · CLI · TypeScript + Bun

ShellShield

Um hook de shell que analisa cada comando com um parser de shell e bloqueia rm -rf /, armadilhas de curl | bash e ataques de homógrafo antes que executem. Feito para terminais onde agentes de IA rodam comandos.

P/02Agentes de IA · Bash · Sandboxes

ibx

Uma skill de agente com um único script bash para usar sandboxes descartáveis do instabox.sh. Evita que dois agentes peguem a mesma sandbox, lida com a pausa por ociosidade, nunca repete um exec que pode ter rodado e se recusa a copiar credenciais. Funciona com Claude Code, Codex e OpenCode.

05 Este site

Como este site foi feito.

HTML, CSS e JavaScript escritos à mão, sem template, framework ou etapa de build. Os números desta seção são medidos agora, no seu navegador.

Ler o código-fonte
  1. a

    Céu em tempo real

    O sol e a lua do topo da página seguem a posição real sobre Natal. Altura, nascer, pôr, fase e inclinação da lua são calculados no seu navegador.

  2. b

    ASCII em WebGL

    A cena é desenhada numa grade de células e cada célula vira um caractere, escolhido pela densidade de tinta medida quando a página carrega. São duas passadas de shader.

  3. c

    Busca com BM25

    A paleta ⌘K busca trechos deste site com BM25, a mesma etapa de recuperação de um RAG. Roda sem servidor e nada sai do navegador.

  4. d

    Acessibilidade

    HTML semântico, navegação completa por teclado, contraste AA e suporte a quem prefere menos movimento.

  5. e

    Idioma e tema

    Português ou inglês, tema claro ou escuro. Tudo troca sem recarregar a página.

  6. f

    Sem rastreadores

    Sem analytics, cookies ou requisições a terceiros. As fontes também são servidas daqui.
